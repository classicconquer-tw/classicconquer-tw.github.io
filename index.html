儲值流程

  1. 點下方「購買天石」，進入官方儲值 Discord。
  2. 在官方儲值頻道告訴 GM 要買的方案和遊戲帳號，照指示付款。
  3. GM 確認收款後，把天石和禮包發到你的帳號。

小心冒充 GM 的詐騙

官方只在官方儲值 Discord 收款，GM 不會主動私訊你要你付款。任何人私訊說可以幫你儲值、便宜賣天石，都是詐騙。私下交易被騙，GM 都無法處理。查到私下買賣天石、帳號或遊戲幣換現金，相關帳號一律停權。

FAQ

常見問題

畫面上的中文變成亂碼

Windows 的「非 Unicode 程式語言」不是繁體中文。照安裝第 2 步改成「中文（繁體，台灣）」並重新開機。

遊戲裡打不出中文

最簡單的方法：下載上方「玩家工具」的打字小幫手，在小視窗打字自動貼進遊戲。或照下面的步驟改用舊版注音：

  1. 設定 → 時間與語言 → 語言與地區 → 中文（繁體）→ 語言選項 → 微軟注音 → 一般
  2. 打開「使用舊版的微軟注音」
  3. 重開遊戲
跳出「Smart App Control 已封鎖」

Windows 安全性 → 應用程式與瀏覽器控制 → 智慧型應用程式控制設定，改成「關閉」。私服登入器常被這個功能誤擋。

怎麼註冊帳號？

不用另外申請。在登入畫面輸入你想要的帳號和密碼，第一次登入就會自動建立。帳號限 4–16 個英文或數字，密碼 4–16 字。如果顯示帳號或密碼錯誤，代表這個帳號已經有人用了，換一個名字再試。

按登入後卡住或連線失敗

先到 Discord 確認伺服器有開。如果 GM 公告換了新版本，請重新下載客戶端。

儲值要去哪裡？怎麼確認是官方？

儲值只在官方儲值 Discord：discord.gg/N6jxp2BD。玩家社群 Discord（discord.gg/DW6V3JHccs）是聊天、組隊、看公告用的。GM 不會主動私訊你要你付款，有人私訊說可以代儲、便宜賣天石，一律是詐騙。

儲值多久會到？

在官方儲值 Discord 付款後，GM 確認收款就會把天石和禮包發到你的帳號。
